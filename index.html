        Status Koneksi Perangkat
        Pilih Jenis Perangkat External I/O

        Koneksi lewat kabel USB memakai Web Serial API - hanya didukung browser Chrome/Edge di desktop/laptop. Firmware: MAPIN_Arduino_Uno.ino. Pin: D2=Trigger IN, D5=OK, D7=BUSY, D13=NG, D8=Error.

        Tidak Terhubung

        ESP8266 terhubung lewat WiFi, melakukan HTTP polling ke Apps Script Web App (endpoint ?action=trigger & ?action=getIoStatus). Pastikan ESP8266 & aplikasi memakai URL Web App & API token yang sama (lihat firmware MAPIN_ESP8266.ino).

        Status koneksi ESP8266 mengikuti status polling di kartu "Status Koneksi Perangkat" di atas - tidak perlu tombol koneksi manual di sisi aplikasi.

        PLC (Ethernet) memakai kontrak HTTP yang sama seperti ESP8266, karena Apps Script hanya bisa menerima HTTP biasa (bukan Modbus/Profinet native). Mapping alamat I/O fisik di sisi PLC (mis. %I0.0/%Q0.0 gaya Siemens, atau X0/Y0 gaya Mitsubishi) menyesuaikan merk PLC masing-masing - dikonsultasikan dengan engineer PLC terkait.

        GET <URL_WEBAPP>?action=trigger&token=<API_TOKEN>
        GET <URL_WEBAPP>?action=getIoStatus&token=<API_TOKEN>
        Simulasi I/O (Lampu Indikator)

        Tampilan lampu ON/OFF untuk tiap pin sesuai perangkat yang dipilih. Tombol "Simulasi Trigger" menjalankan siklus inspeksi penuh tanpa perlu hardware fisik - berguna untuk uji coba software.
